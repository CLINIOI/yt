# Авторизация YouTube (cookies)

YouTube требует подтверждение что ты не бот.
Приложение автоматически пробует три варианта:

───────────────────────────────────────────────
ВАРИАНТ 1 (рекомендуется): cookies.txt
───────────────────────────────────────────────
1. Установи расширение для Chrome/Firefox:
   "Get cookies.txt LOCALLY"
   https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc

2. Открой youtube.com, войди в аккаунт Google

3. Нажми расширение → "Export" → сохрани файл
   ПРЯМО В ПАПКУ ПРОЕКТА с именем:  cookies.txt

4. Перезапусти приложение — скачивание заработает.

───────────────────────────────────────────────
ВАРИАНТ 2: браузер (автоматически)
───────────────────────────────────────────────
Если cookies.txt отсутствует — приложение само
попробует взять куки из Chrome/Firefox/Edge.

ВАЖНО: Chrome 127+ шифрует куки (DPAPI ошибка).
Если видишь "Failed to decrypt with DPAPI":
  → Используй Вариант 1 (cookies.txt)

───────────────────────────────────────────────
ВАРИАНТ 3: yt-dlp вручную
───────────────────────────────────────────────
Если ничего не помогает, скачай вручную:

  yt-dlp --cookies cookies.txt URL

───────────────────────────────────────────────
ВАЖНО: Не делись файлом cookies.txt с другими!
Он содержит данные твоей сессии Google.
