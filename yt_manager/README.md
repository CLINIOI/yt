# YT Manager

Персональный десктопный инструмент для мониторинга YouTube-каналов и автоматической обработки видео.

> Только для локального использования. Никаких серверов, аккаунтов и облаков.

---

## Скриншот

```
╔══════════════════════════════════════════════════════════╗
║  YT Manager  │  📺 Каналы  ← добавление / мониторинг   ║
║  ──────────  │  ⚙️ Обработка ← нарезка, склейка, стек   ║
║  🟢 ffmpeg   │  📁 Папки   ← файловое дерево проекта    ║
║  🟢 yt-dlp   │  📊 Статистика ← графики, активность     ║
║  ──────────  │  🎛 Пресеты ← импорт / экспорт настроек  ║
╚══════════════════════════════════════════════════════════╝
```

## Требования

| Компонент | Версия | Обязателен |
|-----------|--------|------------|
| Python    | ≥ 3.10 | ✅ |
| ffmpeg    | любая  | ⚠ нужен для нарезки и склейки |
| yt-dlp    | ≥ 2024.1 | ⚠ нужен для загрузки видео |

### Установка ffmpeg

- **Windows**: скачай с [ffmpeg.org](https://ffmpeg.org/download.html), распакуй, добавь `bin/` в `PATH`
- **macOS**: `brew install ffmpeg`
- **Linux**: `sudo apt install ffmpeg` / `sudo dnf install ffmpeg`

## Быстрый старт

### Windows

```bat
install.bat
```

Запуск после установки:

```bat
run.bat
```

### macOS / Linux

```bash
chmod +x install.sh run.sh
./install.sh
./run.sh
```

### Вручную (любая ОС)

```bash
# Создать виртуальное окружение
python -m venv .venv

# Активировать
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Запустить
python main.py
```

## Страницы

### 📺 Каналы
- Добавление YouTube-канала по URL
- Автоматическое обнаружение новых видео
- Скачивание одного или нескольких роликов
- Аналитика по каналу (видео, статусы)

### ⚙️ Обработка
- **Нарезка** — режет скачанное видео на клипы заданной длительности
- **Склейка** — объединяет несколько клипов в один файл
- **Стекинг** — накладывает видео вертикально (верх / центр / низ) для TikTok/Reels

### 📁 Папки
- Файловое дерево: `downloads/` → папки каналов → видео
- Быстрый просмотр обработанных клипов и нарезок
- Отдельные папки для фонов и баннеров

### 📊 Статистика
- KPI-карточки: каналов / загружено / обработано / всего
- Горизонтальные бары по каналам
- Кольцевая диаграмма статусов видео
- Линейный график активности (30 дней)
- Таблица последних 50 загрузок

### 🎛 Пресеты
- Сохранение любых настроек обработки как пресет
- Импорт `.json` с чужими пресетами (или просто словарь настроек)
- Экспорт всех пресетов одним файлом
- Применение пресета → автоматически обновляет страницу Обработки

## config.json

Создаётся автоматически при первом запуске:

```json
{
  "app": {
    "window_width":  1280,
    "window_height": 800,
    "window_x": 100,
    "window_y": 100
  },
  "paths": {
    "downloads":   "./downloads",
    "processed":   "./processed",
    "backgrounds": "./assets/backgrounds",
    "banners":     "./assets/banners"
  },
  "download": {
    "max_parallel": 2,
    "format": "bestvideo+bestaudio/best"
  }
}
```

Все пути можно настроить через страницу **Пресеты → вкладка Папки**.

## База данных

Файл `data/app.db` — SQLite, создаётся автоматически. Содержит таблицы:

- `channels` — добавленные YouTube-каналы
- `videos` — видео и их статусы (`new` / `downloaded` / `processed` / `error`)
- `download_queue` — очередь загрузок
- `processing_settings` — настройки обработки по каналу
- `presets` — сохранённые пресеты
